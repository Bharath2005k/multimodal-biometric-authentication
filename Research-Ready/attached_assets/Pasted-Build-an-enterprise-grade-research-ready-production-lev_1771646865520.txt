3) Machine Learning

Keystroke Model:
- LSTM + Attention mechanism
- Input shape: (timesteps, feature_dim)
- Binary classification

Mouse Model:
- RandomForest or XGBoost

Fusion:
- Late fusion weighted risk aggregation
- Adaptive weighting based on model confidence

final_risk = dynamic_weight_k * lstm_prob + dynamic_weight_m * rf_prob

4) Risk Engine
Classify:
0–40 → Normal
40–70 → Elevated Risk
70–85 → Duress
>85 → Forced / Reject

5) Silent Alert Logic
If risk > 70:
   - Insert alert in database
   - Flag session
   - Restrict transaction endpoints
   - Trigger admin notification service

6) Continuous Authentication
Re-evaluate behavior every 3 seconds.
Invalidate JWT if risk > threshold.
